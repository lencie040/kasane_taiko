    重段位道場

    1曲目と2曲目は通常の譜面、3曲目に重譜面が来ます。合格すると、その重譜面が通常プレイでも遊べるようになります。段位の重さは3曲目の重レベル（I〜X）で決まり、I でも本家の六段相当です。

    重なったノーツ

    同じ時刻に置かれたノーツは縦に並んで流れてきます。2個なら2レーン、4個なら4レーンです。

    数と色を揃える

    並んだドンの数・カッの数と同じだけキーを押します。多くても少なくても、その列はすべて不可です。

    特良

    同時押しの全キーが ±18ms 以内に揃うと特良。良より厳しい判定で、段位の合格条件に使われます。

    許容の割合

    条件は「不可 1%以下」「特良 85%以上」のように割合でも書けます。何個まで落とせるかを常に表示します。

    記録

    王冠とベストスコア、段位の合格状況です。行を押すとその譜面を選曲画面で開きます。

        スコア・王冠・段位の合格と解禁・お気に入り・設定・CSV を文字列にして書き出します。ブラウザのデータを消す前や、別のブラウザへ移すときに使ってください。.osz 本体は含まれないので、移した先でもう一度読み込んでください。

        CSV を貼り付けて適用

        1行目の見出しで charts.csv か dan.csv かを自動で見分けます。

        テンプレートを作る

        いま読み込んでいる譜面から CSV の下書きを作ります。コピーして表計算ソフトで編集してください。

        charts.csv — 譜面ごとのコースとレベル

        列内容例
        file.osz のファイル名（拡張子なし可）、曲名（Title / TitleUnicode）、または BeatmapSetID のどれか123456 Artist - Song
        version.osu の難易度名（[Metadata] Version）。* でその曲の全譜面Inner Oni
        courseeasy normal hard oni ura kasane（かんたん／ふつう／むずかしい／おに／裏／重 でも可）ura
        level通常コースは 1〜11（★）。重は I〜X（数字でも可）9 / VII
        memo自由記入（読み飛ばします）。# で始まる行はコメント

        同じ時刻に2個以上のノーツがある譜面は、CSV の指定にかかわらず 重 になります。

        dan.csv — 重段位の構成と合格条件

        列内容
        id name段位の識別子と表示名（name を空にすると「重段位 + 3曲目のレベル」）
        song1 diff1 … song3 diff3各曲の file と version（charts.csv と同じ書き方）。3曲目に重譜面を置きます
        gauge魂ゲージ。98%
        good ok bad良・可・不可。95% のような割合（全ノーツ数に対する）か 12 のような個数
        tokuryo特良。割合は 3曲合計の「同時押しノーツ数」に対する値
        roll連打数。40 のような打数か、秒速12（12/s 12ps でも可）のような秒速。秒速は3曲の黄色い連打の長さの合計 × 秒速 で必要打数を出します（風船は含みません）
        combo score hits最大コンボ・スコア・叩けた数（良＋可＋連打）。combo は割合も可

        条件セルは 赤合格/金合格 の形です。例: bad 列に 1%/0.3%、tokuryo 列に 85%/95%。>= <= を先頭に付けると向きを変えられます（既定は 良・特良・連打などが「以上」、可・不可が「以下」）。空欄の列は条件なしです。

        重レベルの目安

        重の I〜X は★とは別の物差しです。その譜面を解禁する段位が、本家のどの段位くらいの重さかを表します。
