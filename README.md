# 重ね太鼓

## 曲を追加
`content/songs/` に音源と譜面を含む `.osz`（または `.zip`）を置いて main にコミットします。サブフォルダも対応。`content/csv/charts.csv` に難易度設定、`content/csv/dan.csv` に段位設定を置けます。CSVの形式はゲームの読み込み画面を参照してください。GitHub Actions が一覧を自動生成し、Pages に反映します。

GitHub の Settings → Pages → Source を GitHub Actions に設定してください。

## 封印ノーツ
設定で「編集モード」をON（初期状態はOFF）にしてから、曲詳細の「封印ノーツを視覚的に編集」を開き、スライダーで時刻を移動。音符の左右をクリックして配置／解除します。左は左手（標準 D/F）、右は右手（J/K）が不可。同時押しは小ドン1＋小カツ1の列のみ対応します。

編集はブラウザに保存。「封印設定を書き出す」で取得した `noise.json` を `content/noise.json` に置くと他のプレイヤーにも配信できます。ブラウザ内の編集が配信設定より優先されます。

## ローカル起動
Python 3 で `python3 scripts/build.py`、続いて `python3 -m http.server 8000`。ブラウザで http://localhost:8000 を開きます。HTMLの直接起動ではリポジトリの曲自動読込は無効ですが、従来のファイル読込は利用できます。

## 曲フォルダを共有する

設定で「編集モード」をONにすると、曲選択でフォルダを作成できます。フォルダ内で作成すると子フォルダになります。曲を追加するにはフォルダを開いて「このフォルダに入れる」を使うか、曲詳細の「曲のフォルダ」を変更します。分類していない曲は「未設定」に並びます。

「共有用 folders.json」で書き出したファイルをリポジトリの `content/folders.json` に置くと、他のプレイヤーにも配信されます。このブラウザの編集を解除して共有版を確認するには「共有設定に戻す」を使います。

## 月替わり段位と曲の同期

月替わり段位は日本時間の年月で選曲します。同じ譜面は月内の通常段位で1回まで使われ、条件に合う譜面を3つ確保できた段位だけが表示されます。重段位は別枠です。

通常起動では公開ページの一覧、「GitHubから今すぐ取得」では main の一覧を参照します。曲やCSV、封印・フォルダ設定はブラウザにハッシュ付きで保存され、次回は内容が変わったファイルだけを取得します。
