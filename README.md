# 重ね太鼓

## 譜面を作る

設定で「編集モード」をオンにすると、右端に「エディットモード」が表示されます。音源を選んで新しく作るか、「既存譜面を選ぶ」から曲と難易度を選んでください。曲名・作者・難易度で検索し、「譜面を開く」「同じ曲に新規譜面」へ進めます。

- 音源の波形と拍の目盛りを見ながらクリックで配置できます。スナップは16分、24分、32分などから選べます。
- 同じ時刻の別の段に置くと同時押しになります。封印は単音、または小ドンと小カッ各1個の同時押しに設定できます。
- 連打と風船は始点・終点を指定します。スペースキーで試聴、選択ツールで移動、右クリックまたはDeleteで削除できます。
- BPMの候補を自動測定できます。拍の位置や曲中のテンポ変更はタイミング点で調整できます。
- 推定レベルは編集中に更新されます。「難易度の内訳」で、物量、複合の技術、リズム、見た目BPMによる視認性、同時押し、封印ノーツの加点を確認できます。
  ★11.0からは、定数が0.1上がるのに必要な負荷の差を大きくします。
  難易度定数の物量では、BPMと音符の細かさで決まる打間隔を使い、短い高速配置と数秒続く高速配置を別々に測ります。途中で休める時間は持続の負荷に反映します。技術・リズムでは、速い複合、拍の裏から入る配置、24分と32分の混在などを評価します。同色ノーツの交互打ちは、打間隔、連続する打数、速い連打が譜面中に出る頻度を考慮します。交互打ちが必要になる速さの目安は、加点前の難易度によって変わります。
- 「譜面を引用」で曲・難易度と範囲を選び、再生位置に挿入できます。元の拍間隔を引用先のBPMに合わせます。
- 下書きはブラウザに保存できます。完成したらゲーム内で試遊し、.ktzを書き出してください。

## 曲を追加・配信する

.ktz は .osu 譜面と音源などを入れた ZIP 形式で、同梱の `kasane.json` に表示曲名、曲ID、難易度、封印設定、所属フォルダが入っています。ファイルをゲームに読み込むとブラウザに保存されます。配信するときは `content/songs/`（サブフォルダ可）に置いて main にコミットしてください。日本語の曲名とファイル名を使えます。

既存曲の新規難易度や編集済み譜面の出力には、同じ曲IDと他の難易度が入ります。公開ファイルを更新するときは、同じ曲IDの .ktz を複数置かず、元の .ktz を置き換えてください。

ゲーム内のレベルは、既存の .ktz を含めて全譜面から自動推定します。通常譜面は小数第1位まで保持し、たとえば 9.0〜9.4 は ★9、9.5〜9.9 は ★9+ と表示します。★10.0 以上は小数第1位まで、重譜面は I〜X で表示します。

### 旧形式からの移行

「読み込み」タブの「リポジトリ譜面を .ktz に一括変換・ダウンロード」から、公開中の譜面をまとめたZIPを取得できます。展開した `content/` をリポジトリに重ねてコミットできます。変換済みの .ktz がある曲はそのファイルが優先されます。

公開ビルドは、リポジトリ内の旧 .osz／.zip、難易度CSV、封印設定を .ktz に変換します。曲ID・難易度名は従来の記録やフォルダと照合できるよう引き継ぎます。段位CSVがある場合は `content/dans.json` に移します。ブラウザの通常読み込みは .ktz に対応します。

「公開譜面を更新」では公開一覧を確認し、ブラウザに同じ内容の .ktz が保存されている曲は再利用します。

曲選択のコース画面では、譜面レーダーで物量・技術・リズム・視認難・ギミックを確認できます。物量はBPMと音符の細かさで決まる打間隔に加え、密度が続く長さ、総打数、ノーツの間に休める時間を反映します。ギミックには同時押しと封印ノーツによる負荷が反映されます。各軸は全譜面で共通の0〜100の目安です。

GitHub の Settings → Pages → Source は GitHub Actions に設定してください。

## ローカル起動

Python 3.9 以降で `python3 scripts/build.py`、続いて `python3 -m http.server 8000 --directory .site` を実行し、http://localhost:8000 を開きます。ビルド時に `.site/` に公開用ファイルをまとめます。

## 曲フォルダを共有する

設定で「編集モード」をオンにすると、曲選択でフォルダを作成できます。曲詳細の「曲のジャンル」で所属を選び、「ジャンルを保存」を押します。すべてのチェックを外した曲は「未設定」に並びます。

エディターの「所属フォルダ」では複数の所属先を .ktz に同梱できます。フォルダの並び順や共有設定は `content/folders.json` で管理できます。ブラウザ内の編集は「共有設定に戻す」で解除できます。

## 月替わり段位

月替わり段位は日本時間の年月で選曲します。同じ譜面は月内の通常段位で1回まで使われます。重段位は別枠です。

## 弱点道場

通常演奏のリザルトから「弱点に挑戦」を選べます。不可が出た区間を優先し、フルコンボ時は可が出た区間が対象です。難所全体や判定が崩れた部分に近い配置を、デモ曲を除くライブラリから最大4つ出題します。類題は前後の小節も含め、片側最大3秒のノーツを付けて練習できます。配色だけを入れ替えた類題には「ドン・カッ反転」と表示します。近い配置が見つからなければ元の難所へ進みます。再挑戦後の「似た配置をもう一度」からは、1つ目の類題に戻れます。
