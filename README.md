# 重ね太鼓

## 譜面を作る

設定で「編集モード」をオンにすると、右端に「エディットモード」が表示されます。音源を選んで新しく作るか、「既存譜面を選ぶ」から曲と難易度を選んでください。曲名・作者・難易度で検索し、「譜面を開く」「同じ曲に新規譜面」へ進めます。

- 音源の波形と拍の目盛りを見ながらクリックで配置できます。スナップは16分、24分、32分などから選べます。
- 同じ時刻の別の段に置くと同時押しになります。封印は単音、または小ドンと小カッ各1個の同時押しに設定できます。
- 連打と風船は始点・終点を指定します。スペースキーで試聴、選択ツールで移動、右クリックまたはDeleteで削除できます。
- BPMの候補を自動測定できます。拍の位置や曲中のテンポ変更はタイミング点で調整できます。
- 推定レベルは編集中に更新されます。「難易度の内訳」で、物量、複合の技術、リズム、見た目BPMによる視認性、同時押し、封印ノーツの加点を確認できます。
  ★11.0からは、定数が0.1上がるのに必要な負荷の差を大きくします。
  難易度定数の物量では、BPMと音符の細かさで決まる打間隔を使い、短い高速配置と数秒続く高速配置を別々に測ります。途中で休める時間は持続の負荷に反映します。技術・リズムでは、速い複合、拍の裏から入る配置、24分と32分の混在などを評価します。同色ノーツの交互打ちの負荷は物量に含め、打間隔、連続する打数、速い連打が譜面中に出る頻度を考慮します。交互打ちが必要になる速さの目安は、加点前の難易度によって変わります。
- 「譜面を引用」で曲・難易度と範囲を選び、再生位置に挿入できます。元の拍間隔を引用先のBPMに合わせます。
- 「難易度の設定」を「手動設定」にすると、通常・封印は ★1.0〜12.9（0.1刻み）、重は I〜X（1〜10）を指定できます。推定レベルを見比べながら調整でき、設定は書き出す .ktz に保存されます。
- 下書きはブラウザに保存できます。完成したらゲーム内で試遊し、.ktzを書き出してください。

### 封印譜面

「既存譜面を選ぶ」から通常譜面がある曲を選び、「同じ曲に新規譜面」でコースを「封印」にします。移行元の譜面、移行位置、キャラクター（なしも可）と最低Lv、移行前の可と不可の上限、最大コンボの下限を設定します。最大コンボは移行前に一度でも指定数に達すれば条件を満たします。0を指定するとコンボ条件なしです。移行位置はタイムラインに表示されます。解禁後は譜面全体を通常プレイで遊べるので、移行前にあたる部分も配置できます。難易度は ★1.0〜12.9 で自動推定されます。

ポテンシャル9.00以上で移行元を遊び、条件を満たすと、同じ音源のまま封印譜面に切り替わります。ハードモードはライフ100から始まり、可で2、不可で20減ります。残り0で即終了し、残して完走できれば解禁です。移行した回のスコアや成果は保存されません。

封印譜面への自動移行は、譜面ごとに解禁するまで有効です。封印譜面は解禁後に曲一覧に表示され、難易度順と★の絞り込みに含まれます。難易度選択の「もどる」で左カツを10回叩くと封印譜面を選べます。Escまたは「曲選択へ戻る」で曲選択へ戻れます。 オート演奏の「全難易度同時再生」にも、解禁済みの封印譜面が加わります。

## 曲を追加・配信する

.ktz は .osu 譜面と音源などを入れた ZIP 形式で、同梱の `kasane.json` に表示曲名、曲ID、難易度、封印設定、所属フォルダが入っています。ファイルをゲームに読み込むとブラウザに保存されます。配信するときは `content/songs/`（サブフォルダ可）に置いて main にコミットしてください。日本語の曲名とファイル名を使えます。

既存曲の新規難易度や編集済み譜面の出力には、同じ曲IDと他の難易度が入ります。公開ファイルを更新するときは、同じ曲IDの .ktz を複数置かず、元の .ktz を置き換えてください。

ゲーム内のレベルは原則として自動推定します。同梱の `kasane.json` で譜面に `manualLevel` が指定されている場合は、その値を使います。通常譜面は小数第1位まで保持し、たとえば 9.0〜9.4 は ★9、9.5〜9.9 は ★9+ と表示します。★10.0 以上は小数第1位まで、重譜面は I〜X で表示します。

### 旧形式からの移行

「読み込み」タブの「リポジトリ譜面を .ktz に一括変換・ダウンロード」から、公開中の譜面をまとめたZIPを取得できます。展開した `content/` をリポジトリに重ねてコミットできます。変換済みの .ktz がある曲はそのファイルが優先されます。

公開ビルドは、リポジトリ内の旧 .osz／.zip、難易度CSV、封印設定を .ktz に変換します。曲ID・難易度名は従来の記録やフォルダと照合できるよう引き継ぎます。段位CSVがある場合は `content/dans.json` に移します。ブラウザの通常読み込みは .ktz に対応します。

「公開譜面を更新」では公開一覧を確認し、ブラウザに同じ内容の .ktz が保存されている曲は再利用します。

曲選択のコース画面では、譜面レーダーで物量・技術・リズム・視認難・ギミックを確認できます。物量はBPMと音符の細かさで決まる打間隔に加え、密度が続く長さ、総打数、休める時間、速い同色連打を反映します。技術はドン・カッの切り替えや複合を評価し、短い高速複合も反映します。ギミックには同時押しと封印ノーツによる負荷が反映されます。難易度の計算では、両方の負荷に1.5倍の重みをかけます。各軸は全譜面で共通の0〜150の目安です。

GitHub の Settings → Pages → Source は GitHub Actions に設定してください。

## 譜面データベース

公開サイトの `/kasane_taiko/db/` で、公開曲・内部定数・BPM・ノーツ数・譜面レーダーを検索できます。封印譜面の移行元と解禁条件、キャラクターの入手条件も掲載します。Pages のビルド時に公開 .ktz から集計します。

## ローカル起動

Python 3.9 以降と Node.js 24 以降で `python3 scripts/build.py` を実行します。`node multiplayer/local.mjs` で http://localhost:8000 を開けます。ソロプレイだけなら `python3 -m http.server 8000 --directory .site` でも起動できます。

## ジャケ絵

エディットモードの「曲・譜面情報」でジャケ絵を選ぶと、縦横比を保ったまま長辺512px以内に調整し、書き出す .ktz に同梱します。曲全体で1枚を共有し、曲選択と難易度選択に表示します。

.ktz を直接編集する場合は、`kasane.json` の `song.cover` に ZIP 内の画像パスを指定できます。この項目が省略されている場合は、同梱の `cover.png` や `jacket.jpg` なども認識します。

## 鬼レンチャン

通常モードは ★1〜★10 の順に各1曲。通常をクリアすると、★5〜★9 を各1曲、そのあと ★10 を5曲続けるハードモードが解禁されます。各ステージで候補から1曲を選びます。★5+ は ★5 の枠、★10.0〜10.9 は ★10 の枠に入り、同じ曲は1回の挑戦で1度までです。残りをすべて良で叩いても魂ゲージがクリアに届かなくなった時点で脱落します。

## オンライン対戦

カジュアルは ★1.0〜7.9 の公開譜面からランダムに選曲します。ランク戦は近いリーグ同士で対戦し、マスターの対戦相手と難易度はレートで決まります。ビギナーからエリートまでは、完走で1ポイント、勝利で2ポイント獲得します。昇格に必要なポイントは順に12・18・24・30です。ランクはブラウザごとの対戦プロフィールに保存されます。

PC とスマホ・タブレットは別々にマッチングされます。ステージではハイスピードを使えます。キャラクター能力、オート、譜面の反転・ランダム・非表示、個人設定のオフセットや封印ノーツは適用されません。公開譜面に含まれる封印ノーツは両者に共通です。

公開版の既定は [cclass-vspace](https://github.com/Yumenyan/cclass-vspace/blob/main/src/member.js) と同じ PeerJS の公開仲介と番号付きの待機枠です。対戦種別と端末タイプごとに16枠あり、接続時にリーグ・レートを照合します。「相手を探す」で接続と選曲まで進みます。

対戦中は両者の打鍵を WebRTC で送り合い、それぞれのブラウザでスコアと同点時の到達順を計算します。まったく同じ時刻に同点に到達した場合は引き分けです。PeerJS の公開仲介を使う対戦では各ブラウザがランクを保存し、対戦相手のリーグとレートは相手ブラウザの申告値です。別のブラウザプロファイルで2人分の対戦を試せます。

共通サーバーでスコアとランクを管理する構成も使えます。その場合は `npx wrangler deploy` で Worker をデプロイし、GitHub Actions の Repository variable `MATCH_ENDPOINT` に Worker の `https://…/multiplayer` を設定して `Publish game` ワークフローを再実行します。

## 曲フォルダを共有する

設定で「編集モード」をオンにすると、曲選択でフォルダを作成できます。曲詳細の「曲のジャンル」で所属を選び、「ジャンルを保存」を押します。すべてのチェックを外した曲は「未設定」に並びます。

フォルダの背景色に `rainbow` を入力すると、フォルダとその中の曲一覧に淡い虹色のグラデーションが付きます。共有設定では `folders.json` の該当フォルダに `"color": "rainbow"` を指定します。

エディターの「所属フォルダ」では複数の所属先を .ktz に同梱できます。フォルダの並び順や共有設定は `content/folders.json` で管理できます。ブラウザ内の編集は「共有設定に戻す」で解除できます。

## 月替わり段位

月替わり段位は日本時間の年月で選曲します。同じ譜面は月内の通常段位で1回まで使われます。重段位は別枠です。
「失格曲」フォルダとその配下に所属する曲は段位道場の課題曲から外れます。対象曲の重譜面は通常の曲選択から演奏できます。

## 弱点道場

通常演奏のリザルトから「弱点に挑戦」を選べます。不可が出た区間を優先し、フルコンボ時は可が出た区間が対象です。難所全体や判定が崩れた部分に近い配置を、デモ曲を除くライブラリから最大4つ出題します。類題は前後の小節も含め、片側最大3秒のノーツを付けて練習できます。配色だけを入れ替えた類題には「ドン・カッ反転」と表示します。近い配置が見つからなければ元の難所へ進みます。再挑戦後の「似た配置をもう一度」からは、1つ目の類題に戻れます。
